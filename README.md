# AI Breach — test build

Play it: **https://nathanhunter15.github.io/ai-breach-demo/**

Headphones recommended — it opens with about four minutes of voiced scene,
and SPACE skips a line if you would rather read.

Unfinished, and shared for feedback rather than announced. Please don't pass
the link on.

Two benches ship alongside it, and they are tools rather than parts of the game:

- **[the look studio](https://nathanhunter15.github.io/ai-breach-demo/looks.html)** —
  build a shader that reacts to the music. Wear one in the game with
  `?look=<id>`, e.g. `?fight=1&look=gentle-trip`.
- **[the stem studio](https://nathanhunter15.github.io/ai-breach-demo/studio.html)** —
  every loop in the library, with a per-layer effects rack over it.

Saving from the look studio downloads the files here; filing them into the
repo only works against a dev server.
